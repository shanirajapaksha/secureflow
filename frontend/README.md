# Network Intrusion Detection System (NIDS) Dashboard

# Project Overview
This project is a real-time Network Intrusion Detection System (NIDS) dashboard designed to monitor network traffic, detect potential threats, and manage security alerts. It provides a visual interface for security analysts to track network health and identify anomalies.
This project is designed with focusing on our University final year project. we are going to monitor, detect potential threats, and manage security alerts with Machine learning and deep learning model. In this Repository you can see our NIDS' Frontend only.

# Features
- **Real-time Monitoring**: Visualizations of network traffic patterns.
- **Threat Detection**: Automated alerts for potential security breaches.
- **Geographic Mapping**: Visualization of threat origins.
- **Alert Management**: Interface for reviewing and managing security alerts.

# Technology Stack
- **Frontend Framework**: React
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn UI

# Getting Started

# Prerequisites
- Node.js & npm installed

# Installation
1. Clone the repository
2. Navigate to the project directory
3. Install dependencies:
   - npm install
   

# Running the Application
Start the development server:
- npm run dev
